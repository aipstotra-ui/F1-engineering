# Facts

The single home of every F1 number or claim used in code, lessons, missions or the part catalog. Cite rows by ID (`// F-001`, or `[F-001]` in lesson text). Prefer primary sources: FIA technical/sporting regulations, official F1 timing, and official team/F1 releases. The f1-fact-checker blocks a PR that uses a claim missing from this table.

To add a fact: take the next free ID, then fill in every column. To change a value: edit the row and update its source; the ID never changes.
