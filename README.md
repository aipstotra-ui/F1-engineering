# F1 Engineering Lab

Build a realistic Red Bull RB19 part by part, like Lego, learning what every part does. Then tune it and test it on track with a lap simulator, wind tunnel and head-to-head races. Switch to a holographic view for analysis.

Status: Step 2 (part catalog). Roadmap: [PLAN.md](PLAN.md).

## Run it
```bash
npm install
npm run dev
```
Then open http://localhost:5173. Other commands: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`.

The Python lab (`lab/`, from Step 11) uses [uv](https://docs.astral.sh/uv/): `cd lab && uv run pytest`.

Fan-made educational project, not affiliated with Formula 1, the FIA or Red Bull Racing.
